# About

oito2_ui is the design system of the oito2 apps: one look and feel for Linux, Windows, macOS, iOS, Android and the web, built on Material 3.

## Principles

- **Desktop first, touch ready.** Density, control sizes and tap targets follow the platform: compact 34-pixel controls with a pointer, 40-pixel ones on touch screens.
- **Accessible by default.** Text and controls reach the WCAG 2.2 AA contrast ratios on every scheme; components support the keyboard, report their state to assistive technologies and skip their animations when the system asks.
- **Material underneath.** The theme styles the Material widgets too, so an app can mix them with oito2 components.
- **Native window chrome.** Title bars and window controls follow GNOME, KDE, Xfce, COSMIC, Windows and macOS.

## Inspiration

The component catalogue follows the yaru.dart widgets of Ubuntu and the Ark UI headless components; the documentation is organized after the Ark UI documentation.
